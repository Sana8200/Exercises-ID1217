Exercises 2 to 4: Numerical Integration: Compute PI

Compute PI using the numerical integration of the function 4/(1+x*x) from 0 to 1.  The value of this integral is PI. The precision depends on the number of steps (the number of intervals), which could be an input parameter.
  • pi-seq.c -- Sequential version of the PI program

Exercise 2: Compute PI using a parallel construct and SPMD

Create a parallel version of the PI program using a parallel construct. Pay close attention to shared versus private variables.In addition to a parallel construct, you will need the following runtime library routines
int omp_get_num_threads() returns the number of threads in the team;
int omp_get_thread_num() returns thread id or rank in the team (0,..., size-1)
double omp_get_wtime() returns time in seconds since a fixed point in the past. Use this function to estimate the execution time of your program.
  • pi_spmd_simple.c -- Parallel PI program using the openmp parallel construct and an SPMD  algorithm (using the partial sums array).

Exercise 3: Compute PI using a parallel construct and SPMD without false sharing.

In exercise 2, you probably used an array to create space for each thread to store its partial sum. If array elements happen to share a cache line, this leads to false sharing, which in essence “sloshing independent data” back and forth between threads With false sharing, each update invalidates the cache line, in which the non-shared data are stored. Modify your PI program from exercise 2 to avoid false sharing due to the partial sums array.
  • pi_spmd_final.c -- PI SPMD final version without false sharing.

Exercise 4: Compute PI using loops

Go back to the serial pi program and parallelize it with a loop construct. Your goal is to minimize the number of changes made to the serial program.
  • pi_loop.c -- Parallel PI program using the openmp for work-sharing construct with reduction.
  • pi.c -- Parallel PI program using openmp with minimal changes to the serial program.

Exercise 5: Optimizing loops. Matrix multiplication 

Parallelize the matrix multiplication program in the file matmul.c. Try to optimize the parallel program (i.e., improve its execution time) by playing with how the loops are scheduled. N.B. Be careful to whether variables are shared or private. Variables declared inside parallel region are private; whereas variables declared outside parallel region are shared.
  • matmul.c -- Serial matrix multiply, which computes the product C  = A * B.
  • matmul_par.c -- Parallel matrix multiply using OpenMP.
